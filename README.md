# ABTalks – 60 Days of Showing Up

A mobile‑first coding sprint for college students. Build every day, prove your work on GitHub and LinkedIn, and build a public track record that outlasts any tutorial.

## What this is
- 60-day challenge with daily 20‑minute engineering tasks
- Public proof‑of‑work: GitHub commit + LinkedIn post
- Streak tracking with graceful recovery (Exam Shield) for college exam weeks
- Deterministic Momentum Engine that adapts the experience to each student
- Mock data and localStorage – no backend, no auth, no database

## Routes
- `/` – Landing page
- `/dashboard` – Student dashboard
- `/day/12` – Single challenge day

## Thoughtful feature
**Exam Shield & Recovery** – students can protect or recover a missed day when college gets heavy, instead of losing their entire streak.

## Tech stack
React · TypeScript · Vite · Tailwind CSS · Framer Motion · Lucide Icons

## AI usage
All AI interactions are logged in PROMPTS.md.
